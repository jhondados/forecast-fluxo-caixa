# 💰 Forecasting de Fluxo de Caixa

> Previsão de fluxo de caixa com modelos de séries temporais. Antecipa necessidades de capital de giro e otimiza aplicações financeiras.

**🌐 Demo ao vivo (web app interativo):** https://jhondados.github.io/forecast-fluxo-caixa/

## 📊 Resultados-chave (KPIs)
**4.8%** MAPE · **90 dias** Horizonte · **94%** Acerto · **R$ 8M/ano** Economia

## 🧠 Tecnologias de IA
Time Series · Prophet · LightGBM

## ✨ O que faz
- Previsão diária/semanal/mensal
- Detecção de sazonalidade e eventos
- Cenários otimista/base/pessimista
- Alertas de risco de liquidez

## 🗄️ Fonte de dados real
[Banco Central SGS](https://www3.bcb.gov.br/sgspub)

## ⚙️ Como funciona
1. **Coleta de dados reais** — integração com Banco Central SGS
2. **Processamento com IA** — Time Series · Prophet · LightGBM
3. **Dashboard & insights** — KPIs, gráficos e recomendações acionáveis
4. **Ação automatizada** — alertas, predições e decisões em tempo real
